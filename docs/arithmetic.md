# Booth 乘法器与 MAC4

[multiplier](../rtl/multiplier.v) 在 `start` 有效且空闲的上升沿锁存两个 32 位操作数。部分积 `a` 和被乘数 `m` 采用 33 位有符号表示，保留额外的符号位以处理 `-2³¹` 的加减。`q` 保存乘数，附加位 `q_1` 初始为零。

| `{q[0], q_1}` | 移位前的部分积 |
| --- | --- |
| `00` 或 `11` | 保持 |
| `01` | `a + m` |
| `10` | `a - m` |

选择加减后，对拼接的 `{a, q, q_1}` 算术右移一位。接受请求后的 32 个上升沿各完成一次迭代，最后一个上升沿更新 64 位乘积 `z` 并清除 `busy`。忙时收到的启动脉冲会被忽略，完成的结果保持到下一次结果写入或复位。

## 四路点积

[mac](../rtl/mac.v) 将输入字各拆成四个字节。每组字节符号扩展到 32 位，送入一份 Booth 乘法器。四份并行运行，完成后模块在下一拍求和写入 `z`。从接受启动到 `busy` 变低相隔 33 个上升沿。

`mac` 的 32 位输出是四个有符号乘积之和。执行 [MAC4 指令](gemv.md#mac4-编码与数据布局) 时，处理器把这个和加到原来目的寄存器上，因此一行跨多个字时可以连续累加。四路点积的取值范围为 `-65024` 至 `65536`。

执行 `python3 tools/check.py rtl --waves` 后，可以查看 `build/tb_arithmetic.vcd` 中的 `mul_start`、`mul_busy`、`product` 和 `mac_busy`、`dot`。测试覆盖零、异号、同号、32 位最小值、两种 INT8 点积边界和两组连续点积。
